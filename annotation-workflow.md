# Annotation Workflow

1. **Read the task rules:** identify the unit being labelled, allowed labels, exclusions, and escalation process.
2. **Review examples:** use approved examples to understand boundary cases.
3. **Annotate consistently:** apply the same decision rules to similar items.
4. **Flag uncertainty:** do not force a label when instructions require escalation.
5. **Run quality checks:** inspect completeness, allowed labels, format, and consistency.
6. **Document changes:** note guideline clarifications and recurring error types.

## For image or LiDAR work
Document the sensor/data type, frame or point-cloud unit, object classes, annotation conventions, occlusion/truncation rules, and review procedure. Do not publish original project data unless the owner explicitly allows it.
